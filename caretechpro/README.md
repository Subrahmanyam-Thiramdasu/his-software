# CareTechPro - Healthcare Technology Website

A high-end, visually exceptional, fully responsive healthcare technology company website built with HTML, CSS, JavaScript, and GSAP.

## Project Structure

- `index.html` - Main HTML file
- `css/` - Stylesheets organized by architecture
- `js/` - JavaScript files for interactions and animations
- `assets/` - Images, icons, and mockups

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- Vanilla JavaScript (ES6+)
- GSAP & ScrollTrigger for animations
- Lucide Icons
